# react-slotz

Teleport React components to anywhere in the react-tree (slot/fill). Published to npm as `@marimo-team/react-slotz`.

## Development

```bash
pnpm install
pnpm test        # vitest
pnpm lint        # biome check --write . (autofix.ci runs this on PRs)
pnpm typecheck   # tsc --noEmit
pnpm build       # unbuild -> dist/
pnpm ci          # typecheck + lint + test
```
